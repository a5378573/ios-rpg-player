# 构建与侧载

## 前置条件

- 一个 GitHub 账号
- 一台 Windows 电脑（不需要 Mac）
- 一台 iPhone / iPad，系统 **iOS 17 或更高**（引擎的静态库按 iOS 17 编译）
- 一个 Apple ID（免费即可，用于签名）

## 零、引擎二进制从哪来

App 里的原生引擎不是从源码编的，而是从上游 release 拉预编译包：

```bash
sh Scripts/fetch_engine.sh
```

脚本会下载 `mkxp-z-ios.tar.gz`（80 MB）和 `angle-apple-prebuilt.tar.gz`（31 MB），
校验 sha256 后解压到 `Vendor/`。CI 里也会跑同样的脚本，并按版本号缓存 `Vendor/`。

`Vendor/` 已在 `.gitignore` 里，**不要提交**（267 MB，且属于第三方构建产物）。

## 一、推到 GitHub

在 `ios-rpg-player` 目录下初始化仓库：

```bash
cd ios-rpg-player
git init
git add .
git commit -m "init: RPG盒子 iOS 外壳"
git branch -M main
git remote add origin https://github.com/你的用户名/rpg-player.git
git push -u origin main
```

**建议用 public 仓库**。macOS runner 在 private 仓库里按 10 倍时长计费，public 仓库免费。

## 二、触发云端构建

1. 打开仓库页面 → **Actions** 标签。
2. 左侧选 **Build unsigned IPA**。
3. 右上角 **Run workflow** → 分支选 `main` → 运行。
4. 首次运行会失败在 XcodeGen 或 SPM 解析上，属正常，看日志修。

构建大约 10–15 分钟（首次要下载 112 MB 引擎包，之后走缓存）。

成功后：

- **Artifacts** 里下载 `RPGPlayer-unsigned-ipa`
- 解压得到 `RPGPlayer-unsigned.ipa`（约 90–110 MB，引擎静态库占了大部分）

产物是**未签名**的，直接装会报错，必须走下一步签名。

## 三、用 Sideloadly 签名安装

### 准备

1. 下载 [Sideloadly](https://sideloadly.io/)（Windows 版）。
2. 安装 **iTunes**，必须是 Apple 官网下载的版本，**不要用 Microsoft Store 版**（缺少驱动）。
3. 数据线连接 iPhone，手机上点「信任此电脑」。

### 安装

1. 打开 Sideloadly，左上角会自动识别设备。
2. 把 `RPGPlayer-unsigned.ipa` 拖进 **IPA** 框。
3. **Apple ID** 填你的账号。
4. 点 **Start**，输入 Apple ID 密码（如果开了双重认证，需要在弹窗里填验证码，或去 appleid.apple.com 生成专用密码）。
5. 等进度条走完，手机上出现「RPG盒子」图标。

### 信任证书

第一次点图标会提示「不受信任的开发者」：

1. 设置 → 通用 → VPN与设备管理
2. 找到你的 Apple ID，点进去
3. 点「信任」

然后就能打开了。

## 四、7 天过期怎么办

免费 Apple ID 签的证书 **7 天后失效**，App 会打不开。三种处理：

**方案 A：AltStore 自动续签（推荐）**

- 电脑装 [AltServer](https://altstore.io/)，手机装 AltStore
- 手机和电脑连同一个 Wi-Fi，AltServer 在后台时会自动帮你重签
- 需要电脑定期开机

**方案 B：手动重签**

每 7 天用 Sideloadly 重新走一遍安装流程，**游戏和存档不会丢**（在同一设备上覆盖安装即可）。

**方案 C：开发者账号**

$99/年，证书 1 年有效，还能装到多台设备。如果长期用，这个最省事。

**方案 D：TrollStore（仅特定设备）**

A12 及以下芯片、iOS 14.0–16.6.1 的越狱/半越狱环境可以永久签名，不需要证书。新设备不适用。

## 五、导入游戏

App 支持两种导入方式：

**方式一：应用内导入（推荐）**

1. 在电脑上把游戏文件夹压缩成 **ZIP**（不要 RAR / 7z）。
2. 把 ZIP 传到 iPhone（微信文件传输、iCloud Drive、隔空投送都行）。
3. 打开 App → 右上角 **+** → 选 ZIP。
4. 自动解压、识别引擎、加入游戏库。

> ZIP 内的文件名必须是 UTF-8。如果导入后文件名变成乱码或提示缺文件，用 7-Zip 重新打包，压缩时把文件名编码选成 UTF-8。

**方式二：文件 App 直接放**

1. 数据线连电脑 → 打开 iTunes / 访达 → 文件共享 → RPG盒子
2. 把解压后的游戏文件夹拖进 `Games` 目录
3. 重启 App，会自动扫描到

> 注意：方式二要求游戏目录结构完整，例如 MV/MZ 必须有 `www/index.html` 或根目录 `index.html`。

## 六、常见报错

| 现象 | 原因 | 处理 |
|---|---|---|
| `The application could not be verified` | 证书没信任 | 设置 → 通用 → VPN与设备管理 → 信任 |
| `Maximum number of apps for free development profiles has been reached` | 免费账号最多 3 个自签 App | 删掉不用的自签 App 再装 |
| `Provision failed` / `Invalid credentials` | Apple ID 密码错或需要专用密码 | 去 appleid.apple.com 生成 App 专用密码 |
| 安装成功但闪退 | 架构不对 | 确认 workflow 里 `ARCHS=arm64`，且设备不是越狱冲突环境 |
| iOS 17+ 提示需要开发者模式 | 系统限制 | 设置 → 隐私与安全性 → 开发者模式 → 打开并重启 |
| 游戏白屏（MV/MZ） | 缺 `index.html` 或目录多套了一层 | 检查 ZIP 解压后是否有 `www/index.html` |
| 导入后提示「未识别引擎」 | 文件不完整或加密 | 确认 `data/System.json`、`Game.ini` 或 `RPG_RT.ldb` 存在 |

## 七、本地 Mac 构建（可选）

如果你以后有 Mac：

```bash
brew install xcodegen
cd ios-rpg-player
xcodegen generate
open RPGPlayer.xcodeproj
```

在 Xcode 里选自己的开发者账号，直接 Run 到真机。这种方式调试最方便，也能看实时日志。
